## Note Template

모든 문제는 **[결정적 근거 - 조심할 것 - 패턴 - 코드]** 4단계 양식을 준수하여 기록합니다. 

### 1. 💡 핵심
 
* 문제를 읽자마자 특정 알고리즘을 선택하게 만든 **'결정적 근거'**를 기록합니다.
* **알고리즘 선정 이유:** 왜 이 방식이 가장 효율적인지 짧게 요약합니다.
* 예: "최단 거리" + "가중치 없는 격자" $\rightarrow$ **BFS**

### 2. 주의 사항

* 직접 겪은 **시행착오**나 **예외 케이스**, **문법적 실수**를 기록합니다.
* 예: `map` 예약어 충돌 주의, 인덱스 `n-1` 사용, 재귀 깊이 제한 등

### 3. 코드 설계 흐름

* 코드를 작성하기 전 머릿속으로 그린 **로직의 순서**를 번호를 매겨 정리합니다.
* 다른 문제를 풀 때도 적용할 수 있는 **일반적인 뼈대**가 됩니다.

### 4. ☁️ 최종 정답 코드
* 주석을 통해 로직의 흐름을 상세히 설명합니다.
* 가독성이 좋고 가장 효율적으로 최적화된 최종본을 보관합니다.
