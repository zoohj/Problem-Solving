## [문자열] 백준 - 1316. 그룹 단어 체커

> **핵심 키워드:** *#문자열 #중복제거 #set #GroupWord*

[https://www.acmicpc.net/problem/1316](https://www.acmicpc.net/problem/1316)

### 1. 💡 핵심

* > **"연속해서 나타나는 문자는 하나로 합치고, 그 결과에서 중복된 문자가 있는지 확인하면 끝!"**


* **그룹 단어의 정의:** 각 문자가 연속해서 나타나는 경우만 인정함. 즉, 한 번 떨어진 문자가 나중에 다시 나타나면 안 됨.
* **압축 로직:** `aabbbcc` → `abc`로 압축한 뒤, 이 문자열에 중복된 알파벳이 없다면 그룹 단어임.

---

### 2. 주의 사항

* **중복 체크 테크닉:** 파이썬에서 배열/문자열의 중복 요소 여부를 확인할 때는 **`len(자료구조) == len(set(자료구조))`** 공식을 사용함. `set`은 중복을 허용하지 않으므로, 중복이 있다면 길이가 줄어듦.
* **연속 문자 처리:** 현재 문자가 바로 직전 문자(`com_word[-1]`)와 같다면 무시하고, 다를 때만 리스트에 추가하여 중복을 압축함.
* **공백 및 개행:** `input().strip()`을 사용해 문자열 끝의 개행 문자를 제거해야 정확한 길이를 계산할 수 있음.

#### + 🧸 Related concepts

* **`itertools.groupby`:** 파이썬 내장 라이브러리를 사용하면 `[k for k, g in groupby(word)]` 한 줄로 연속 문자를 압축할 수 있음.
* **`dict` / `set` 탐색:** 이미 등장했던 문자인지 매번 `in` 연산자로 확인하며 진행하는 방식도 가능함.

---

### 3. 코드 설계 흐름

1. **입력:** 단어의 개수 `n`과 각 단어를 입력받음.
2. **압축:** 단어를 순회하며 직전 글자와 다른 글자가 나올 때만 `com_word`에 저장함. (연속 중복 제거)
3. **검증:** 압축된 리스트 `com_word`의 길이와 이를 집합으로 만든 `set(com_word)`의 길이를 비교함.
4. **카운트:** 두 길이가 같다면(중복된 문자가 다시 나타나지 않았다면) `count`를 1 증가시킴.

---

### 4. ☁️ 최종 정답 코드

```python
import sys

input = sys.stdin.readline
n = int(input())
count = 0

for _ in range(n):
    word = input().strip()
    if not word: continue
    
    # 1. 연속된 중복 문자 압축 (예: aabbbca -> abca)
    com_word = [word[0]]
    for i in range(1, len(word)):
        if word[i] == com_word[-1]:
            continue
        com_word.append(word[i])

    # 2. ⭐️ 핵심: 중복 요소 있는지 확인 (set 활용)
    # 압축된 결과에서 전체 길이와 중복 제거(set) 길이가 같다면 그룹 단어
    if len(com_word) == len(set(com_word)):
        count += 1

print(count)

```
