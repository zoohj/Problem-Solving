## [분할 정복] 백준 - 1629. 곱셈

> **핵심 키워드:** *#분할정복 #거듭제곱 #나머지연산 #O(logB)*

[https://www.acmicpc.net/problem/1629](https://www.acmicpc.net/problem/1629)

### 1. 💡 핵심
* > **지수를 절반씩 줄여나가는 논리** 그 자체가 분할 정복의 핵심! <br>`result`가 **언제 갱신**되는지 이해하기 🔥

* **지수 법칙:** $A^{10} = (A^5)^2$ 임을 이용하여, 똑같은 계산을 두 번 하지 않고 결과를 제곱하여 연산 횟수를 획기적으로 줄임.
* **나머지 연산:** $(A \times B) \pmod C = ((A \pmod C) \times (B \pmod C)) \pmod C$. 곱셈 결과가 너무 커져 연산 속도가 저하되기 전에 계속 나머지를 취해줌.

---

### 2. 주의 사항

* **시행착오 - 단순 반복문:** $B$가 최대 약 21억이므로 $O(B)$ 방식은 절대 0.5초 제한을 통과할 수 없음.
* **오버플로우 방지:** 파이썬은 정수 오버플로우가 없으나, 숫자가 거대해지면 곱셈 연산 자체의 시간 복잡도가 증가함. 매 단계마다 `% C` 필수.
* **홀수 지수 처리:** $B$가 홀수일 때, 삐져나오는 $A$ 하나를 `result`에 곱해주는 타이밍이 정확해야 함.
* **밑(A) 전처리:** 시작 전 `a %= c`를 수행하여 밑의 크기를 미리 줄여두는 것이 안전함.

#### + 🧸 Related concepts

* **Modular Inverse:** 나눗셈이 포함된 나머지 연산에서 필요한 개념.
* **Matrix Exponentiation:** 피보나치 수열 등을 $O(\log N)$에 구할 때 이와 동일한 분할 정복 논리가 쓰임.

---

### 3. 코드 설계 흐름 (B=13 예시)

1. **준비:** `result = 1`, `a %= c`.
2. **반복:** `while b > 0:` 지수가 0이 될 때까지 실행.
3. **홀수 처리:** `b % 2 == 1`이면 현재까지 제곱된 `a`를 `result`에 곱하고 `% c`.
4. **제곱:** `a`를 스스로 제곱하여 다음 단계를 준비 (`a = (a * a) % c`).
5. **절반:** 지수를 반으로 나눔 (`b //= 2`).

---

### 4. ☁️ 최종 정답 코드

```python
import sys

input = sys.stdin.readline

a, b, c = map(int, input().split())

result = 1  

# 1. 미리 나머지 연산하여 숫자를 줄여둠
a %= c 

# 2. 지수(b)가 0이 될 때까지 반복 (O(log B))
while b > 0:
    # 3. 지수가 홀수라면 삐져나온 a를 결과에 곱해줌
    if b % 2 == 1:
        result = (result * a) % c
        
    # 4. 밑(a)을 스스로 제곱함 (A^1 -> A^2 -> A^4 -> A^8 ...)
    a = (a * a) % c
    
    # 5. 지수(b)를 절반으로 줄임
    b //= 2
    
print(result)

```
