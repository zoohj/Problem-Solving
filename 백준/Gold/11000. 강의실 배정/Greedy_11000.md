## [Greedy] 백준 - 11000. 강의실 배정

> **핵심 키워드:** *#그리디 #최소힙 #정렬 #IntervalOverlap*

[https://www.acmicpc.net/problem/11000](https://www.acmicpc.net/problem/11000)

### 1. 💡 핵심

* > **"가장 빨리 끝나는 강의실을 찾아 재사용하고, 안 되면 새로 만든다. 이때 '가장 빨리 끝나는 곳'은 최소 힙이 찾아준다!"**


* **정렬의 이유:** 강의를 시작 시간 순환대로 배치해야 현재 사용 가능한 강의실이 있는지 차례대로 검사할 수 있음.
* **힙(Heap)의 역할:** 현재 사용 중인 강의실들의 **종료 시간**들을 관리. `heap[0]`은 항상 가장 빨리 비는 강의실을 가리킴.

---

### 2. 주의 사항

* **강의실 재사용 조건:** `시작 시간 >= heap[0]`(기존 강의 종료 시간)인 경우에만 재사용이 가능. 이때 `heappop`을 통해 기존 종료 시간을 갱신(제거 후 새 종료 시간 push).
* **정렬 기준:** 종료 시간이 아닌 **시작 시간**을 기준으로 정렬. (종료 시간 기준 정렬은 '한 강의실에서 할 수 있는 최대 강의 수'를 구할 때 주로 사용됨)
* **시간 복잡도:** $N=200,000$이므로 $O(N^2)$ 브루트 포스는 불가능. 정렬과 힙을 이용한 $O(N \log N)$ 풀이가 필수.
* **입력 속도:** `sys.stdin.readline`을 사용하지 않으면 대량의 데이터 입력 시 시간 초과가 발생할 수 있습니다.

#### + 🧸 Related concepts

* **회의실 배정 (BOJ 1931):** 한 강의실에서 최대한 많은 회의를 하는 문제 (종료 시간 기준 정렬).
* **작업 스케줄링:** 여러 프로세스를 최소한의 리소스로 처리하는 유사 유형.

---

### 3. 코드 설계 흐름

1. **입력 및 정렬:** 강의 정보를 리스트에 담고 시작 시간 순으로 오름차순 정렬.
2. **첫 강의 처리:** 첫 번째 강의의 종료 시간을 최소 힙에 삽입.
3. **순회 및 비교:** 두 번째 강의부터 끝까지 다음을 반복.
   * `현재 강의 시작 시간 >= 힙의 최솟값(가장 빠른 종료 시간)` 이면?
   * 강의실 재사용 가능 $\rightarrow$ `heappop` 실행.

   * 현재 강의의 종료 시간을 `heappush`.


4. **결과:** 최종적으로 남아있는 힙의 크기(`len(heap)`)가 필요한 최소 강의실 개수.

---

### 4. ☁️ 최종 정답 코드

```python
import heapq
import sys

input = sys.stdin.readline

n = int(input())
# 1. 강의 시간을 입력받고 시작 시간 기준으로 정렬
time_table = []
for _ in range(n):
    time_table.append(list(map(int, input().split())))

time_table.sort() # 시작 시간 기준 오름차순

# 2. 종료 시간을 관리할 최소 힙 생성
# 첫 번째 강의의 종료 시간을 먼저 넣고 시작
heap = []
heapq.heappush(heap, time_table[0][1])

for i in range(1, n):
    start, end = time_table[i]
    
    # 3. ⭐️ 핵심: 현재 강의 시작 시간이 가장 빨리 끝나는 강의실의 종료 시간보다 크거나 같다면
    # 해당 강의실을 이어서 사용할 수 있으므로 기존 종료 시간을 비워줌(pop)
    if start >= heap[0]:
        heapq.heappop(heap)
    
    # 4. 새로운 종료 시간을 추가 (재사용했다면 갱신, 안 됐다면 새 강의실 추가 효과)
    heapq.heappush(heap, end)

# 힙에 남아있는 원소의 개수가 곧 필요한 총 강의실의 개수
print(len(heap))


```
