## [BFS] 백준 - 7576. 토마토

> **핵심 키워드:** *#BFS #멀티소스BFS #격자탐색 #날짜계산*

[https://www.acmicpc.net/problem/7576](https://www.acmicpc.net/problem/7576)

### 1. 💡 핵심

* > **익은 토마토가 여러 개라면? 모든 시작점을 동시에 큐에 넣고 출발하는 '멀티소스 BFS'!**


* **동시 확산:** 여러 지점에서 동시에 번져나가는 탐색은 BFS의 전형적인 특징. 모든 시작점을 큐에 미리 넣음으로써 "동시에 하루가 지나는" 상황을 구현.
* **날짜 누적:** `box[nx][ny] = box[x][y] + 1`을 통해 별도의 변수 없이 격자 자체에 경과 시간을 기록.

---

### 2. 주의 사항

* **시행착오 - 시작점 설정:** 익은 토마토(1)를 발견할 때마다 BFS를 호출하는 것이 아니라, **모든 익은 토마토의 위치를 먼저 큐에 다 집어넣은 뒤** 딱 한 번의 BFS를 실행.
* **방문 체크 생략:** 안 익은 토마토(0)가 익은 토마토(1 이상)로 변하므로, `if box[nx][ny] == 0` 조건이 방문 체크 배열(`visited`)의 역할을 대신함.
* **인덱스 범위 체크 순서:** `0 <= nx < n and 0 <= ny < m`를 `box[nx][ny] == 0`보다 먼저 확인해야 `IndexError`를 방지할 수 있음.
* **결과 보정:** 시작점의 값이 `1`부터 시작하므로, 최종 결과에서 `max_num - 1`을 해주어야 실제 경과 일수.
* **예외 처리:** 처음부터 모든 토마토가 익어있는 경우(`zero_cnt == 0`)와 BFS 종료 후에도 안 익은 토마토가 남은 경우를 구분.

---

### 3. 코드 설계 흐름

1. **입력 및 준비:** 박스 상태를 입력받으며 **익은 토마토**(1)의 위치는 큐에 담고, **안 익은 토마토**(0)의 개수를 세어둠.
2. **초기 검사:** `zero_cnt`가 0이면 이미 다 익은 상태이므로 `0`을 출력하고 종료.
3. **BFS 탐색:** 큐가 빌 때까지 사방을 탐색하며 `0`을 발견하면 `현재 값 + 1`을 저장하고 큐에 삽입.
4. **최종 확인:** 박스를 전체 순회하며 `0`이 남아있으면 `-1`, 아니면 `최댓값 - 1`을 출력.

---

### 4. ☁️ 최종 정답 코드

```python
import sys
from collections import deque

input = sys.stdin.readline

# m: 가로, n: 세로
m, n = map(int, input().split())
# 토마토 박스 입력
box = [list(map(int, input().split())) for _ in range(n)]

queue = deque()
zero_cnt = 0  # 안 익은 토마토 개수

# 1. 초기 상태 탐색 및 시작점 큐 삽입
for i in range(n):
    for j in range(m):
        if box[i][j] == 1:
            queue.append((i, j))  # 이미 익은 토마토 → BFS 시작점
        elif box[i][j] == 0:
            zero_cnt += 1

# 2. 방향 벡터 (상, 하, 좌, 우)
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

def bfs():
    while queue:
        x, y = queue.popleft()
        for i in range(4):
            nx = x + dx[i]
            ny = y + dy[i]
            
            # 3. ⭐️ 인덱스 범위 확인을 먼저 수행 (IndexError 방지)
            if 0 <= nx < n and 0 <= ny < m:
                # 아직 안 익은 토마토인 경우만 전염
                if box[nx][ny] == 0:
                    box[nx][ny] = box[x][y] + 1  # 날짜 누적 (이전 칸 + 1)
                    queue.append((nx, ny)) # 새로 익은 토마토를 큐에 추가

# 처음부터 모든 토마토가 익어있다면 0 출력
if zero_cnt == 0:
    print(0)
else:
    bfs()

    # BFS 종료 후 결과 확인
    max_num = 0
    feasibility = True

    for i in range(n):
        for j in range(m):
            # 4. 박스를 순회하며 최댓값 갱신 및 익지 않은 토마토 확인
            if box[i][j] == 0:
                feasibility = False
            max_num = max(max_num, box[i][j])

    if not feasibility:
        print(-1) 
    else:
        print(max_num - 1) 

```
